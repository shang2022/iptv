# 山东市县（闪电新闻融媒平台）

山东台「闪电新闻」的融媒平台（app.litenews.cn，图床 img11.iqilu.com / img11.litenews.cn）给省内大量区县融媒体中心和部分地市台托管客户端与直播。本模块收录其中 224 路电视频道，按地市分成「山东-济南」…「山东-菏泽」16 个分组（默认排在「山东」后面），每轮刷新只输出主清单取得到的台。

模块默认关闭：两百来路区县台并进「山东」会把省台淹掉，看的人又大多只关心自己县的一两个台。想看的在「源管理」打开，不需要的地市整组隐藏（分组隐藏按名字记，不受频道主键影响）。

频道表来自 issue #196 群友的 Node 脚本（131 个机构），2026-10-24 逐台核对：

| 主清单 404 或连不上（停推） | 26 | 收录，停推期间不输出，恢复后自动出现 |

德州转发的「临邑综合频道」（179/52）在另一家 CDN 上，沙箱里没连通，没有和临邑台自己的 49/3 比对过画面，先按重复处理。

## 官方接口

- 频道：`https://app.litenews.cn/v1/app/play/tv/live?orgid=<机构号>`，免登录、不看 Referer。`data[]` 每条有 `id`、`name`、`stream`、`logo`、`icon`。未知机构回 `code:1, data:[]`。
- 节目单：`https://app.litenews.cn/v1/app/play/tv/program?orgid&channelid&time=<unix 秒>`，见 epg.js。
- 分享页：`https://<机构自己的域名>/share/<base64("tvl-<orgid>-<id>")>.html`，页面里直接写死 `stream`，没有别的接口。

## 取流

- `stream` 是入口主清单，带 `k`、`t` 两个参数，每次请求都换。alivealone302 上的去掉 `k`、把 `t` 改成几天前照样 200；blivealone302 上的 `t` 是约一小时后的整点，去掉签名就取不到。
- 不能把地址写进播放列表：频道主键按地址算（只剥 sign、token、expire 这类已知时效参数），`k`、`t` 一变主键就变，用户对这台的隐藏、改名、换组、排序每轮刷新都会失效。所以播放列表写固定的 `sdcounty-<orgid>-<id>`，播放时 resolve 给当前地址、app 回 302。接口结果按机构缓存 20 分钟，刷新时取到的直接进缓存。
- 主清单只有一档，指向网宿 CDN（`*.100ycdn.com`）上的子清单，子清单带 `wsBindIP=2`，按取主清单的出口 IP 绑定。所以必须 302 让播放器自己取主清单，不标 `relayHls`。`?relay=1` 兼容模式（给不跟随 302 的播放器）下主清单由本机取，子清单绑的是部署机出口，播放器和部署机同一出口（同一个家）才能播。
- 少数台在别的 CDN（`blivealone302` / `elivealone302`、腾讯云、`*.iqilu.com`）；停推时有的回 404，有的连接一直挂着。刷新时逐台取一次主清单（8 秒超时），取不到就当停推。
- 每轮约 130 次接口请求加 220 次主清单请求，并发 6，实测 40 秒左右。

## 台标与节目单

- 台标：接口 `logo`（频道标）优先，没有再用 `icon`（多是所属电视台站标；个别机构把 m3u8 地址填在 icon 里，只认图片地址）。潍城、蓬莱、利津、黄岛、城阳、台儿庄给的是节目片头、宣传海报或风景图，不用。长清生活借长清综合的长清台标，齐河、禹城借德州市台转发条目上的县融媒体中心台标。其余约 30 台官方没图，暂时留空。
- 节目单：只有崂山频道排了当天起往后几天；其余台不带 `time` 时退回旧的同星期编排（多数停在 2022～2026 年间），不用。

## 可达性

只在本机（家宽出口）测过。海外部署能不能取到接口、播放器能不能直连网宿 CDN 没有验证。
